NodePhell 0.2.0 expands dependency input support and records successful use with
PCB Timelapse and ACE-Step.

## Install from source

```sh
git clone https://github.com/JustTryingToGetSomeWorkDone/NodePhell.git
cd NodePhell
./bin/nodephell launcher install
nodephell --version
```

NodePhell itself requires Python 3.11 or newer. Keep the checkout: the installed
commands run its source directly. To update an existing checkout, run
`git pull --ff-only` there and rerun `./bin/nodephell launcher install`.

The optional FreeCAD adapter is included in the source tree:

```sh
nodephell plugin add ./plugins/freecad
```

## Changes

- Persistent requirements profiles for `sync`, `lock`, and `update`, including
  nested requirements and constraints, markers, indexes, and direct references.
- HTTPS PEP 508 direct references, compatible duplicate constraints, uv named
  indexes, and editable uv path sources.
- Separate accelerator profiles with fingerprinted inputs and included files.
- Guidance for incomplete requirements profiles.
- SHA-256 recovery for resolved HTTPS artifacts whose indexes omit hashes,
  with insecure and credential-bearing artifact URLs rejected.

## Validation

- All 203 unit tests passed.
- PCB Timelapse 1.0.0 and 1.3.0 rendered from KiCad using the same dependency
  configuration through the NodePhell Python shim.
- ACE-Step 1.5's ROCm launcher opened the web interface and generated music on
  an AMD Radeon 880M using the shared Python runtime and dependency profile.
